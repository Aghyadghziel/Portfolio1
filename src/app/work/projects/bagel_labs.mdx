## Overview

Led the development of a full-stack SaaS platform at Bagel Labs, contributing as a Frontend Lead and Full Stack Developer. The platform enables users to fine-tune AI models and manage subscription-based access to advanced models such as VEO 3, Flux, and a variety of image and video models. The project focused on secure authentication, scalable data management, subscription payments, and a modern, responsive user experience for AI developers and creative teams.

## Key Features

- Authentication & Authorization
  Implemented a secure authentication system using NextAuth.js, supporting OAuth providers (Google, GitHub) and role-based access control to manage user permissions for both general users and admins.
- Model Access & Deployment
  Built a model deployment and fine-tuning system with real-time monitoring and status tracking. Users can deploy, test, and fine-tune AI models, including image, video, and text models.
- Subscription Management
  Integrated Stripe to manage subscriptions for accessing premium AI models, handling billing, plan upgrades, and transaction workflows securely.
- Data & File Management
  Developed a robust data management system supporting file uploads, processing pipelines, and validation logic, ensuring users can safely upload datasets for model fine-tuning.
- Admin Console
  Designed an admin dashboard for user management, system monitoring, and operational controls to support platform administration and internal workflows.
- UI & Frontend Architecture
  Led the frontend architecture, building responsive and accessible UI components using Radix UI and modern React patterns for a seamless user experience.

## Technologies Used

- Next.js & React – Frontend architecture and server-rendered applications
- Stripe – Subscription and payment processing
- Radix UI – Accessible, composable UI components
- AWS (DynamoDB, S3) – Cloud infrastructure and data storage
- TypeScript – Type-safe frontend and backend development

## Challenges and Learnings

Balancing fast iteration with long-term scalability and security was a key challenge. Ensuring smooth fine-tuning workflows for multiple AI models while maintaining subscription access controls required careful system design. Coordinating full-stack features across authentication, payments, AI model deployment, and cloud infrastructure strengthened my end-to-end development skills and remote team collaboration.

## Outcome

The platform successfully enabled users to fine-tune and deploy AI models while managing subscriptions for advanced models like VEO 3 and Flux. The modular frontend and admin tooling reduced maintenance overhead, improved observability, and accelerated feature delivery, providing a scalable foundation for future AI-driven products.
