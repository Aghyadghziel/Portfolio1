## Overview

Led the development of a full-stack collaboration platform at Alpha Factory, enabling seamless partnerships between influencers, designers, and video editors. The platform allows influencers to submit video content, request editing and thumbnail design services, and handle payments via PayPal or cryptocurrency. Built with a scalable architecture and a modern, responsive frontend, the system also includes a robust admin panel for platform management.

## Key Features

- \*\*Influencer Workflow
  Enabled influencers to upload videos and submit requests for editing and thumbnail design. Users can track project progress, communicate with designers/editors, and receive final deliverables directly through the platform.
- Designer & Editor Collaboration
  Developed a dashboard for designers and editors to accept requests, submit drafts, and manage revisions, streamlining the creative workflow between all parties
- Payments & Monetization
  Integrated PayPal and cryptocurrency payments to handle project fees, including secure checkout, payment tracking, and transaction history for both influencers and service providers.
- Admin Panel
  Built a comprehensive admin dashboard to manage users, monitor projects, approve or reject submissions, and handle disputes or issues, ensuring smooth platform operations.
- UI & Frontend Architecture
  Designed a responsive and user-friendly frontend with React and Next.js, focusing on accessibility, real-time updates, and seamless interaction between platform roles.
- File Management & Data Processing
  Implemented secure file uploads, storage, and validation for video files and thumbnails, using Prisma for database management to ensure data integrity and scalability.

## Technologies Used

- Next.js & React – Frontend architecture and server-rendered applications
- Node.js & Express – Backend API and request handling
- PayPal API & Cryptocurrency Payment Gateways – Secure payment processing
- Prisma – Database management and structured storage
- TypeScript – Type-safe frontend and backend development
- Radix UI / Tailwind CSS – Responsive, modular, and accessible UI components

## Challenges and Learnings

Coordinating workflows between multiple user roles (influencers, designers, editors, admins) while maintaining a secure and scalable payment system was a key challenge. Implementing real-time project status updates, handling large video files efficiently, and integrating multiple payment options taught important lessons in full-stack architecture, database design with Prisma, cloud storage management, and cross-role collaboration.

## Outcome

The platform successfully facilitated collaboration between influencers and creative teams, allowing seamless video editing, thumbnail design, and payments. The modular architecture, Prisma-managed database, and admin dashboard streamlined operations, reduced friction between platform users, and provided a scalable foundation for future expansion of services.
